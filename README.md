# GeLearner

Небольшое веб-приложение для изучения грузинского алфавита и слов — в игровом
формате, без занудных уроков.

🔗 [ge.zlgvpn.org](https://ge.zlgvpn.org)

## Режимы

### 🔤 Собери слово

Слово на грузинском показывается целиком, а внизу — карточки с русскими
буквами (в том числе двойные, вроде «дж» для ჯ). Нужно тапать карточки по
порядку и собрать транслитерацию слова. Есть уровень с лишними, отвлекающими
карточками — для тех, кому легко.

### 🎯 Как читается буква

Показывается одна грузинская буква и несколько вариантов её чтения
по-русски. Три уровня сложности: чем выше, тем каверзнее похожие по звучанию
буквы среди вариантов.

### ⌨️ Напиши слово

Слово на грузинском показывается целиком — нужно набрать с клавиатуры, как
оно читается по-русски.

---

В каждом режиме видно серию правильных ответов подряд (стрик), счётчик
верных/неверных попыток и точность в процентах. После каждого ответа
показывается перевод слова и то, как оно правильно читается. Темы слов
(числа, еда, животные, города и т.д.) выбираются в настройках режима.
