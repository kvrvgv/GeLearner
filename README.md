# GeLerner

Веб-приложение для изучения грузинского алфавита. Бэкенд — Django + Django REST
Framework, фронтенд — React (Vite + TypeScript).

## Режимы

1. **Собери слово** — слово на грузинском показывается во весь экран, снизу —
   карточки с русскими буквами (в том числе двойные вроде «дж» для ჯ). Нужно
   тапать карточки по порядку, чтобы собрать транслитерацию слова. Две
   сложности: без лишних карточек и с лишними. Если ошибся и нажал не ту
   карточку — тапни по квадратику в поле ввода, и буква вернётся в низ, в пул.
2. **Как читается буква** — показывается одна грузинская буква и несколько
   вариантов её чтения по-русски. 3 уровня сложности: чем выше уровень, тем
   больше вариантов и тем они «каверзнее» (похожие по звучанию буквы).
3. **Напиши слово** — слово на грузинском показывается во весь экран, нужно
   ввести с клавиатуры, как оно читается по-русски.

Во всех режимах неверный ответ подсвечивается красным и поле очищается для
повторной попытки. В режимах 1 и 3 при правильном ответе показывается
перевод слова, подсвеченный зелёным.

Слова и категории хранятся в базе данных и легко редактируются/дополняются
через Django admin (`/admin/`) — можно добавлять новые категории и слова, не
трогая код.

## Backend (Django)

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

python manage.py migrate
python manage.py seed_data      # заполняет буквы, категории и ~230 слов
python manage.py createsuperuser  # для доступа к /admin/

python manage.py runserver 0.0.0.0:8000
```

API доступно на `http://localhost:8000/api/` (`/categories/`, `/letters/`,
`/words/`). Админка — `http://localhost:8000/admin/`.

## Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173/`. Адрес API берётся из
`frontend/.env` (`VITE_API_BASE`).

## Добавление слов и категорий

Проще всего — через Django admin (`/admin/`): там можно создавать категории и
слова, транслитерация проверяется вручную (или можно доверить полю
`ru_translit`, если ввести его самостоятельно). Также можно расширить список
`WORDS` в `backend/learning/management/commands/seed_data.py` и повторно
запустить `python manage.py seed_data` (команда идемпотентна — существующие
слова обновятся, а не задублируются).
